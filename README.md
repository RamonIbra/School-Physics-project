# School-Physics-project
Particle Physics simulation Project
**Description**
This Python code is designed to simulate interactions between charged particles. It utilizes Pygame for visualization, NumPy for calculations, and Matplotlib for plotting the results. The script allows the user to explore the dynamics between particles under various initial conditions.

**Usage**
To run the simulations:
1. Initial Positions: You can comment or uncomment different code snippets for initial positions to test four different simulations.
2. Switching Particles: Toggle between simulating like-charged particles and particles with equal mass. This results in different dynamics within the simulation.
